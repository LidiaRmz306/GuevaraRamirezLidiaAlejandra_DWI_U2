# Sistema de Inscripción a Cursos

## Descripción

Sistema web desarrollado para la gestión de inscripción a cursos. El proyecto permite trabajar con información relacionada con cursos y usuarios mediante una aplicación web.

## Tecnologías utilizadas

- Laravel
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Git
- GitHub

## Control de versiones

El proyecto utiliza Git para el control de versiones y GitHub como repositorio remoto. La rama principal utilizada es `main`.
